# 3D terrain, hillshade and contours in React + Mapbox (final)

The finished app from the Geo Intelligence Lab video. Run it:

```bash
npm install
cp .env.example .env     # put your public Mapbox token (pk.…) in .env
npm run dev
```

Then open http://localhost:5173. Mount Kenya in 3D: Mapbox Terrain-DEM for the relief and the hillshade, Mapbox Terrain for the contours, peaks from OpenStreetMap. See the repo README for how it works.
